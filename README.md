🇩🇪 Tu Alemán Diario
App web progresiva (PWA) para aprender alemán en 15 minutos al día, con enfoque en conversación cotidiana, cocina, viajes y humor.
✨ Funcionalidades

Tarjetas de vocabulario organizadas por semana y categoría
Audio de pronunciación alemana nativa (vía Web Speech API)
Práctica de pronunciación con micrófono y feedback palabra a palabra
Progreso guardado automáticamente en el navegador
Instalable en el móvil como app sin pasar por ninguna tienda

🚀 Cómo usar
Abre la app directamente en el navegador:
👉 https://TU-USUARIO.github.io/deutsch-lernen/
Para instalarla en el móvil, abre la URL en Chrome o Brave y acepta el banner de instalación que aparece automáticamente.
🎤 Requisitos para audio y micrófono

Audio: requiere Google Text-to-Speech instalado en el sistema (Android) o una voz alemana en Configuración → Voz (Windows)
Micrófono: funciona en Chrome y Brave; no disponible en la app de Claude

🛠 Tecnología
Construida con React 18 y Babel standalone — no requiere ningún proceso de compilación. Un solo archivo HTML que funciona en cualquier navegador moderno.
